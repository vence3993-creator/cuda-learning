# W2 D2：shared memory + transpose v2（2026-09-20）

**目标**：用 shared memory 把 naive transpose 不合并的那一端搬到片上重排，让 global 读写两端 sectors/request 都回到 4。

代码：`week02/day02/transpose_smem.cu`，n = 4096，block = 32×32。

## 性能（`make run`，median）

| Kernel | ms | GB/s | % copy | % peak(448) |
|---|---|---|---|---|
| copy | 0.4027 | 333.3 | 100.0% | 74.4% |
| copy_smem | 0.4278 | 313.7 | 94.1% | 70.0% |
| transpose_naive | 0.7688 | 174.6 | 52.4% | 39.0% |
| transpose_smem_v2 | 0.5517 | 243.3 | 73.0% | 54.3% |

v2 / naive = **1.39×**

## ncu 关键指标

| Kernel | ld sec/req | st sec/req | shared ld 趟数/指令 | DRAM 读 | DRAM 写 | achieved occ. |
|---|---|---|---|---|---|---|
| copy | 4 | 4 | – | 67.33 MB | 54.68 MB | 49.79% |
| copy_smem | 4 | 4 | 1.00 | 68.07 MB | 58.88 MB | 64.58% |
| naive | 4 | **32** | – | 69.55 MB | 60.30 MB | 40.43% |
| v2 | 4 | 4 | **32.05** | 68.77 MB | 62.93 MB | 64.89% |

理论 occupancy 全部 66.67%：1024 线程/block，每 SM 上限 1536，只能驻留 1 个 block。

## 预测 vs 实测

| 项 | 预测 | 实测 | |
|---|---|---|---|
| 所有 requests / sectors 计数 | 524,288 的整数倍 | 完全一致 | ✓ |
| v2 shared ld wavefronts | 32× | 32.05× | ✓ |
| DRAM 读 | ≈ 67.11 MB | 67.3–69.6 MB | ✓ |
| DRAM 写 | ≤ 67.11 MB | 54.7–62.9 MB | ✓ |
| copy_smem / copy | 85–100% | 94.1% | ✓ |
| v2 / copy_smem | 60–70% | **77.5%** | ✗ 偏悲观 |

v2 偏差：冲突多出 16.28M 趟，完全串行应多花约 0.181 ms，实测只多 0.124 ms（68%）。高估了 `__syncthreads` 对两个阶段的隔离，约 1/3 的冲突开销和其他 warp 的 global 访存重叠掉了。

## 结论

1. **v2 消灭了不合并访问**：global 两端 sectors/request 都回到 4。代价转移到 shared：按列读 `tile[tx][ty]` 时 bank = ty，32 路冲突，每条 LDS 走 32 趟。
2. **naive 的浪费止于 L2，不在 DRAM**：L1→L2 写事务 8×，DRAM 写只比 copy 多约 10%。L2 把零碎写合并回了完整 cache line，naive 慢在片上事务数，不在显存带宽。
3. **achieved occupancy 高 ≠ 快**：copy 最快但 achieved 只有 49.79%；两个 shared 版本最高却更慢。它只反映 warp 驻留得久不久。
4. **32×32 配置喂不饱这张卡**：纯 copy 只有峰值的 74.4%。Little's law：每 SM 在途约 4 KB，全卡 144 KB，反推延迟约 432 ns；跑满 448 GB/s 需要约 194 KB 在途，缺口比例和带宽缺口一致。

## 其他记录

- `bank_conflicts` = `wavefronts` − 指令数，恒等，两者冗余，以后只看 wavefront 比值。
- ncu duration 不进性能表：ncu 每次 replay 清缓存，naive 慢 18%、v2 慢 12%；bench 连跑时 64 MB 输入部分留在 32 MB L2 里，绝对值略偏乐观，横向比较仍成立。

## 待解问题
